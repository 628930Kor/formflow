# FormFlow

### One form. Any website. Your own backend.

FormFlow is an open-source form backend that makes
it easy to collect, manage, and process form
submissions from any website.

Built for developers who want a simple,
flexible, and self-hostable solution.

## ✨ Features

- Simple form submission API
- Modern dashboard
- Multiple form management
- Email notifications
- Spam protection
- Webhook integrations
- Submission analytics
- API key authentication
- Self-hosting support
- Dark mode

## 🚀 Tech Stack

- Next.js
- React
- TypeScript
- Node.js
- PostgreSQL
- Tailwind CSS

## 🎯 Why FormFlow?

Developers shouldn't have to build an entire
backend just to receive contact form submissions.

FormFlow aims to make form handling simple,
reliable, and accessible.

## 🛠️ Getting Started

Clone the repository:

    git clone https://github.com/628930kor/formflow.git

Navigate to the project:

    cd formflow

Install dependencies:

    npm install

Start the development server:

    npm run dev
